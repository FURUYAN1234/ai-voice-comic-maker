# v1.9.6 - Emergency stop / 緊急停止

Add prominent red emergency-stop controls for API checks and the ordinary production pipeline. Idle/stopped controls are disabled; entered keys/settings and completed videos remain. / API接続確認と通常の制作経路に目立つ赤い緊急停止を追加します。待機中・停止済みは無効にし、入力キー・設定・完成済み動画を保持します。

Propagate cancellation through Gemini/OpenAI, pronunciation, local speech and rendering; suppress fallback and late results. Release only the current pipeline owner's lock after its work settles, then clean temporary session files. / Gemini/OpenAI・発音補助・ローカル音声・描画へ中断を伝え、フォールバックと遅延結果を遮断します。実行終了後に所有者一致のロックだけを解放し、一時ファイルを片付けます。

Update bilingual instructions and Japanese PDF guides. API-provider processing/billing cancellation is not guaranteed. / 英日説明と日本語PDFを同期します。API側の処理・課金停止は保証しません。

Keep emergency stop fixed at the top-right while scrolling, and keep full model descriptions/prices in their own panel. / スクロール中も緊急停止を画面右上へ固定し、モデル説明・料金は専用パネルで全文を表示します。

Hide emergency stop in initial empty API setup; reserve a 76px top band in the workspace, with a 20px top gap. / 初期API入力では緊急停止を隠し、作業画面では上部76pxを予約して上端から20pxの余白を確保します。

- [model-selection] File selection and drag/drop use the currently selected OpenAI model. Live route labels follow explicit server trial/adoption events; existing fallback rules are unchanged. / ファイル選択・ドロップで現在のOpenAI選択モデルを送信します。実行中の試行・採用はサーバーの明示イベントへ対応し、既存フォールバックは維持します。
- [input-preservation] Keep the selected image for explicit retry after stopping, and show only one upper-right emergency-stop button while preserving progress. / 停止後も選択画像を保持して明示的に再実行でき、進捗を残して右上の緊急停止を1つに統一します。
