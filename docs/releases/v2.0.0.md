# Short Movie v2.0.0

## Fix / 修正

- Fixed an issue where the printed title could appear as dialogue and be spoken again after the opening title call. Characters still speak genuine dialogue that happens to match the title. / 題字が台詞として扱われ、冒頭のタイトルコールに続いて本編でも読み上げられる不具合を修正しました。登場人物が題字と同じ文言を話す台詞は保持します。
- Fixed playback and downloads when Short Movie is installed in a path with a hidden folder. The completed screen can reopen the same MP4 after a reload while the original file is retained. / 隠しフォルダーを含む場所にShort Movieを配置しても、完成動画を再生・ダウンロードできるよう修正しました。動画の保存期間内なら、完成画面を再読込して同じMP4を保存できます。
