# AI Voice Comic Maker v1.9.0

## English

### What's New

- Further strengthened browser security while retaining the existing creation workflow.
- Added Content Security Policy controls for scripts and connections, disabled inline event handlers, and hid the app inside external frames.
- Updated dependencies and made fresh security checks mandatory for every deployment. A failed audit or security regression check stops publication.
- Added PNG/JPEG/WebP content checks before image processing and retained previous materials when rejecting an unsupported upload.

## 日本語

### 更新内容

- 既存の制作フローを保ちながら、ブラウザーのセキュリティをさらに強化しました。
- CSPでスクリプト実行・通信先を制御し、HTML内のイベント属性を禁止。他サイトのフレーム内では操作画面を表示しません。
- 依存ライブラリを更新し、毎回のデプロイで最新のセキュリティ検査を必須にしました。監査や回帰テストが不合格なら公開を停止します。
- 画像処理前のPNG・JPEG・WebP内容チェックを追加し、対応外のアップロードを拒否した場合も以前の素材を保持します。

## Protection scope / 防御の範囲

GitHub Pages uses a CSP meta policy and a frame visibility guard; local servers also send defensive response headers. These measures are additional protection, not a guarantee of absolute security. / GitHub PagesではCSP metaとフレーム内の表示拒否を使用し、ローカルサーバーでは防御ヘッダーも設定します。これらは追加の防御であり、絶対的な安全性を保証するものではありません。
