# ai-voice-comic-maker v1.8.9

## Changes / 変更内容

- Validate actual PNG/JPEG/WebP signatures and reject mismatched uploads before image decoding; update Remotion/sharp. / PNG・JPEG・WebPの実ヘッダーを照合し、偽装ファイルを画像処理前に拒否。Remotion・sharpを更新。
- Restrict scripts, connections, frames and forms with CSP; no-referrer policy and direct-tab frame guard. / CSPによる実行・通信・埋め込み・フォーム制限と参照元送信抑止を追加。
- Update vulnerable production and development dependencies. / 本番・開発依存の既知脆弱性を更新。
- Mandatory current dependency/source checks before every deployment and built-policy verification after every build. / デプロイごとの最新依存・ソース検査とビルド後の防御設定検証を必須化。

## Limitations / 制約

GitHub Pages does not provide custom security response headers; the deployed app uses a CSP meta policy and a fail-closed frame visibility guard. Local servers also send defensive response headers. This does not guarantee absolute security. / GitHub Pagesのヘッダー制約に合わせてCSP metaと埋め込み時の表示拒否を使用。ローカルサーバーでは防御ヘッダーも設定します。絶対的な安全性の保証ではありません。
