# v1.8.8

## 日本語
- APIとVite UIをloopbackへ限定し、Host/Origin検査、一時セッション認証、変更操作のCSRF検査を追加。認証情報を永続保存しません。
- 画像アップロードをPNG/JPEG/WebP 1枚・20 MiB以下に制限し、JSONリクエストも64 KiBに制限。
- Remotionを専用workerで実行し、Nodeの制作素材・proxyサーバーもloopbackと同一Originに制限。正常・失敗・取消時の終了を検証。
- 生成画像・音声・BGMを.runtimeへ分離。public配下の既存素材を消さず、公開buildは.nojekyllとLICENSE.txtだけを明示的に許可。
- 以前公開ブランチへ混入した制作素材37件をローカルへ保全し、Git blob SHAと保存内容のSHA256・サイズを照合したうえで、現在の公開サイトから除外。過去のGit履歴は変更しません。
- 無料利用・生成物の商用利用と、アプリ本体の有料再配布等の条件をFURU利用条件に明示。第三者の権利・ライセンスは維持。
- 回帰検証: API等17件、runtime/build 3件、描画2件を確認。無課金の合成画像・音声fixtureでMP4生成/全デコード、正常・失敗・取消後のNode待受閉鎖を検証。新たな課金API実行は行っていません。

## English
- Bind the API and Vite UI to loopback; validate Host/Origin, use an ephemeral local session and require CSRF protection for mutations. No persistent authentication credential is created.
- Limit uploads to one PNG/JPEG/WebP image up to 20 MiB and JSON requests to 64 KiB.
- Run Remotion in a dedicated worker that confines its Node asset/proxy listeners to loopback and the same origin; verify cleanup after success, failure and cancellation.
- Store generated images, voices and BGM in .runtime. Preserve legacy public files locally while allowing only .nojekyll and LICENSE.txt into static builds.
- Preserve all 37 previously published production files locally, verify Git blob SHA, saved SHA256 and byte counts, and exclude them from the current published site. Historical Git commits are not rewritten.
- Publish FURU terms covering free app use, commercial use of generated output, and restrictions on paid redistribution of the app, while retaining third-party rights and notices.
- Validation: 17 API/existing regressions, 3 runtime/build checks and 2 renderer tests. A synthetic image/audio MP4 was rendered and fully decoded without a paid API call; Node listeners closed after success, failure and cancellation.
