# Voice Comic Maker v1.9.4

## Changes / 更新内容

- [models] Use explicit stable Gemini text and vision models: 3.8 Flash, 3.6 Flash, 3.5 Flash-Lite and 3.1 Flash-Lite. / Geminiの文章・画像解析候補を3.8 Flash、3.6 Flash、3.5 Flash-Lite、3.1 Flash-Liteへ更新しました。
- [routing] Remove the retiring 2.5 Flash/Pro routes and floating aliases; align model displays with requests. / 終了予定の2.5 Flash／Proと移動する別名への依存を解消し、表示と実際の候補を一致させました。

- [pronunciation] Use Flash-Lite models for pronunciation assistance. / 発音補助にはFlash-Liteモデルを使用します。
- [dependencies] Update build and release dependencies to address newly reported security issues. / 新たに報告された脆弱性に対応するため、ビルド・公開用の依存パッケージを更新しました。
