# AI音声コミックメーカーで漫画を動画化する

1. 入力画像のページ順とコマ順を確認する。既存の漫画に声とカメラを付ける依頼で使う。新規の漫画制作や説明原稿のナレーションには、その作業に対応するスキルを選ぶ。
2. 解析結果を各コマの原画と照合する。話者、台詞、吹き出しの順番、発音を確認する。フッターや余白の制作クレジットと、物語中の看板・擬音・ナレーションを区別する。下端にあるという理由だけで物語内の文字を除外しない。
3. Gemini APIで接続すると「Gemini 3.8 Flash TTS」が初期選択される。解析後の配役画面で、話者一人ずつとタイトルコールを標準30音声から選ぶ。複数コマでの同名話者は同じ声を使う。MCPでは自動配役を使うか、解析上の名前に一致する `geminiVoices` と、必要に応じて `geminiTitleVoice` を渡す。OpenAI APIで接続すると、利用可能な場合はVOICEVOXが初期選択される。完成動画では実際に割り当てられた声と台詞を確認する。認識・校正・合成のどこで失敗したかを確認し、成功済みの工程や指定した音声を理由なくやり直さない。
4. 試聴と実MP4で、発話順、発音、重複や語尾の欠け、吹き出しとカメラの対応、画面外の切れを確認する。見本や解析台本だけで動画の完了を報告しない。
5. MCPを使う場合は、対象アプリの接続と、その環境に公開されているツールの入力・出力を先に確認する。接続できなければ、利用できる通常画面か台本の照合を進め、どこまで実施したかを伝える。
